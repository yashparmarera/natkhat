# Natkhat Café — Project Overview

## 1. Introduction
**Natkhat Café** is a single-location Indian food outlet providing authentic Desi flavours: spiced earthen Kulhad Chai, piping-hot tawa-stuffed parathas with Amul butter, daily executive and maharaja thalis, and evening Indo-Chinese street savouries.

This application is a focused, mobile-first food ordering website and management system tailored exclusively for Natkhat Café. It is **not** a multi-vendor aggregator or marketplace.

## 2. Core Value Proposition
- **Lightweight, Zero-Friction Ordering**: Customers do not need to install mobile apps or register user accounts.
- **Direct WhatsApp Order Handoff**: Customers browse the menu, build a basket with accurate INR totals, specify delivery/pickup instructions, and launch a pre-filled WhatsApp message sent straight to the café's kitchen.
- **Manual Staff Confirmation**: Café staff reviews the itemized request on WhatsApp and directly confirms food preparation time and payment arrangements (Cash/UPI on delivery or counter).
- **In-House Café CMS**: The café team has direct administrative tools to update menu pricing, mark dishes out of stock, change WhatsApp ordering numbers, and edit homepage announcements.
